# AI 디렉터 저장 위치·출처 필터 v1.2.4

AI 디렉터에서 최종 채택하면 테마 라이브러리로 이동합니다. 기존 ‘테마 출처·상태’ 드롭다운의 ‘AI 디렉터’를 자동 선택하고 이전 검색어를 지웁니다. 추천 테마 탭에는 이슈 기반 주간 추천 실행을 유지합니다.

- 전체 자동 테스트 **368개 통과**. 저장 성공 후 이동·필터 자동 선택·검색 초기화·재채택 방지, 신규 및 이전 디렉터 테마 분류, 검색어와 출처 필터 조합, 주간 추천과 채택 실행 구분을 검증했습니다.
- 새 채택의 DB·이력·반환 메타데이터는 `AI_DIRECTOR` 출처입니다. 원자적 세 파일 저장과 기존 테마·추가 열·이력·작품 보존, 동일 채택 재시도는 임시 CSV와 격리한 원격 대역으로 검증했습니다.
- 기존 `AI_GENERATED` 디렉터 테마는 초안·채택 식별자와 이력으로 인식합니다. 이전 CSV를 일괄 수정하지 않습니다. 디렉터 테마를 별도로 재사용한 정상 주간 추천은 유지합니다.
- 로컬 PC 1366px·모바일 390px에서 실제 저장 자료의 디렉터 테마가 필터에 표시되고 화면 가로 넘침이 없음을 확인했습니다.
- 공개 배포의 버전 **1.2.4**와 PC·모바일 출처 필터를 확인했습니다. 기존 추천 생성 버튼·디렉터 입력·OTT·쿠팡플레이·이미지도 통과했습니다.
- 검증용 테마를 운영 DB에 추가하지 않았습니다. 작업 시작 시 반영한 사용자 저장 자료 기준 `8786067` 대비 테마 DB·추천 이력·추천 작품·콘텐츠 CSV 변경은 없습니다. 정상 이슈·OTT 수집은 별도로 보존했습니다.
