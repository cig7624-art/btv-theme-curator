# v1.2.5 API 비용 표시 검증

- 기존 기능 포함 384개 unittest 통과, 추가 비용 UI 5개 unittest 통과.
- 실제 OpenAI 응답 반환 직후 네 엔진의 세션 집계를 검증했습니다. 화면 재실행·조회는 모델 호출이나 응답 수 증가를 일으키지 않습니다.
- 월 사용액 조회는 별도 관리자 키와 명시적 프로젝트를 모두 요구합니다. 페이지 누락·권한 오류·다른 프로젝트·월 경계·예산 초과·10분 캐시를 격리된 응답으로 검사했습니다.
- 1366px PC, 390px·320px 모바일 브라우저에서 비용 버튼 높이 28px, 실제 결제·사용 내역 링크, 상세 열기·닫기, 라이브러리 화면의 동일 버튼, 오류·가로 넘침 없음을 확인했습니다.
- 사용자 테마·이력·콘텐츠·OTT 저장 파일을 변경하지 않았습니다. 검증용 대화나 채택을 실행하지 않았습니다.
- 관리자 비용 조회 연결이 제공되지 않아 실제 잔액·실청구액을 테스트했다고 주장하지 않습니다. 월 사용액·예산 연동은 선택 설정이며 기본 화면은 잔액 확인 링크를 표시합니다.

공개 배포 결과는 `deployment_validation.json`의 버전과 `api_cost_control` 검사를 확인합니다.
