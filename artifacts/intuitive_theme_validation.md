# v1.2.6 테마 생성 검증

- 기존 기능을 포함한 전체 unittest 409개 통과.
- 사용자가 제시한 닮은 장르·비 오는 날의 추억·가을밤 가족 감상·가족 미스터리 방향을 선정하고, 지표 보고형·복잡한 줄거리 나열형은 제외하는 회귀 검증을 추가했습니다.
- 실제 생성 진입점에서 모델 응답을 대역으로 제공해 주제·포함·제외 기준·참고 후보가 유지되는지 검사했습니다. 모델 호출 횟수는 기존과 같습니다.
- 테마·추천 이력에 저장된 기준을 복원하고 주간 콘텐츠 새로고침 및 라이브러리 작품 업데이트에 전달하는 것을 확인했습니다. 이전 행과 운영 추가 열을 보존합니다.
- 신규 테마 카드의 감상 카피를 검사했고, 이전 형식의 테마 처리도 유지합니다.
- 실제 생성 확인은 별도의 개발 브랜치 작업으로 운영 ‘테마 생성하기’를 한 번 눌러 정상 주간 추천을 추가합니다. 운영 화면의 실제 모델·저장을 사용하며 이전 묶음을 보존합니다. 모델 호출이 발생하고, 클릭 이후에는 자동 재시도하지 않습니다.

공개 화면 검증은 `deployment_validation.json`, 실제 새 주간 묶음 검증은 `weekly_live_validation.json`의 결과를 확인합니다. 이 문서만으로 실제 모델 호출 성공을 주장하지 않습니다.
