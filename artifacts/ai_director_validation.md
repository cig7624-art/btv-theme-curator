# AI 디렉터 v1.2.3 검증

AI 디렉터는 시작 선택 없이 원하는 소재·장르·분위기를 직접 입력하는 대화 화면입니다. 기본 테마 1개와 실제 추천 작품을 바로 만들고 다음 대화에서 고칩니다. 추천 테마의 기존 이슈 기반 생성 기능은 유지합니다.

- 전체 자동 테스트 **357개 통과**.
- PC 1366px·태블릿 768px·모바일 390/320px에서 입력창이 바로 보이며 시작 버튼·방향 선택 카드·전역 수정 선택이 없고 가로 넘침이 없음을 확인했습니다.
- 공개 앱 버전 `1.2.3`을 PC·모바일에서 확인했습니다. 기존 추천 테마 생성·콘텐츠 버튼, OTT 주요 소식과 쿠팡플레이 이미지도 배포 검증을 통과했습니다.
- 실제 OpenAI 연결로 **5회 대화**를 검증했습니다. 최초 자유 요청에서 사전 선택·확인 질문 없이 **테마 1개와 실제 추천 작품 8편**을 생성했습니다. **포스터 8/8개**가 실제 브라우저에서 로딩됐습니다.
- 이어진 대화로 제목만 수정하고, 다른 항목을 보존하며 분위기를 바꿨습니다. 특정 작품을 제외·교체한 뒤 이전 버전으로 복구했습니다. 모바일 폭으로 바꿔도 초안 내용이 유지됐고 가로 넘침이 없었습니다.
- 검증용 초안을 운영 DB에 채택하지 않았습니다. 기존 테마 DB·추천 이력·작품 후보·콘텐츠 CSV를 변경하지 않았으며 OTT 스냅샷은 정상 수집으로 별도 갱신합니다.
