# AI 디렉터 v1.2.0 검증

실제 공개 앱에서 버전 `1.2.0`과 네 개 탭을 확인했습니다. 배포 검증은 PC·모바일 모두 통과했으며 OTT 주요 소식 이미지 6개와 쿠팡플레이 소식·이미지도 정상 로딩됐습니다.

- 전체 자동 테스트: **335개 통과**. 기존 이슈·추천 열람·라이브러리·OTT 테스트를 포함합니다.
- 실제 LLM 검증: 자유 요청으로 **테마 3개, 각 6편**을 생성했습니다. 콘텐츠 DB와 대조했고 추천 이유를 확인했습니다. **포스터 18/18개**가 실제 브라우저에서 로딩됐습니다.
- 이어진 대화에서 2번 테마명만 변경했고 다른 테마·카피·기획 의도·작품을 보존했습니다. 2번의 특정 작품만 제외·교체한 뒤 이전 버전으로 복구했습니다. 모바일로 폭을 바꿔도 초안을 유지했고 화면 가로 넘침이 없었습니다.
- 채택 저장은 임시 CSV와 격리한 원격 저장 대역으로 검증했습니다. 기존 행·추가 열·이력·라이브러리 연결 보존, 중복 채택 방지, 실패·동시 변경 보호를 확인했습니다. 실제 대화 검증에서는 채택 버튼을 누르지 않아 운영 DB에 테스트 테마를 추가하지 않았습니다.
- 코드 도입 전 `v1.1.0` 대비 `theme_pool.csv`, `theme_recommendation_history.csv`, `theme_content_candidates.csv`, `content_db.csv`의 변경은 없습니다. OTT 스냅샷은 정상 정기 수집으로 별도 갱신합니다.
- 코드 롤백 미리보기와 임시 Git 저장소의 데이터 보존 테스트가 통과했습니다. 기존 고정 태그는 그대로 유지했습니다.
