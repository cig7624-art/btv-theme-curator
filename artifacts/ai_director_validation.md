# AI 디렉터 v1.2.2 검증

추천 테마는 기존 이슈 기반 생성·콘텐츠 새로고침 화면으로 복원했습니다. 테마 라이브러리의 문장형 AI 검색을 독립 AI 디렉터 대화로 옮겼습니다. 라이브러리의 빠른 검색·상태 필터·다운로드·작품 관리는 유지합니다.

- 자동 테스트 **356개 통과**. 검색 결과 배치를 대화 아래로 옮긴 뒤 관련 UI 회귀검증 12개도 통과했습니다.
- 공개 앱에서 정확한 버전 `1.2.2`, 네 개 탭, 추천 테마 생성·콘텐츠 버튼, OTT 주요 소식과 쿠팡플레이 이미지가 PC·모바일에서 정상 표시됐습니다.
- 실제 OpenAI 연결로 **7회 대화/선택**을 수행했습니다. ‘뭐 만들어볼까?’에는 초안을 강제로 만들지 않고 기획 방향을 제안했습니다. ‘2번 방향’ 후 테마 3개·각 6편을 만들고 제목만 수정·작품 제외 교체·이전 버전 복구를 확인했습니다.
- 실제 저장 테마 **5개**를 대화 안에서 검색했습니다. 그중 하나의 ‘새롭게 기획’으로 기존 초안 3개를 보존하고 새 초안 1개를 추가했습니다. 모바일 폭으로 바꿔도 내용이 유지되고 가로 넘침이 없었습니다.
- 최초 18개 작품은 실제 콘텐츠 DB로 대조했습니다. 포스터 주소 16개가 실제 브라우저에서 모두 로딩됐으며 나머지 2개는 작품명 카드로 남았습니다. 주소나 이미지를 임의로 만들지 않습니다.
- 채택 저장은 임시 CSV와 격리한 원격 저장 대역으로 검증했습니다. 주간 재생성에도 기존 디렉터 채택 이력·최신 테마·추가 열이 보존되는 회귀검증을 추가했습니다. 실제 공개 대화에서는 채택 버튼을 누르지 않아 운영 DB에 검증용 테마를 추가하지 않았습니다.
- `v1.2.0` 도입 당시 대비 `theme_pool.csv`, `theme_recommendation_history.csv`, `theme_content_candidates.csv`, `content_db.csv`를 변경하지 않았습니다. OTT 스냅샷은 정상 수집으로 별도 갱신합니다.
