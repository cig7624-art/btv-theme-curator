# B tv+ AI Theme Curator

현재 버전은 `v1.5.0`입니다. **지금 주목할 이야기 → 추천 테마 → AI 디렉터 → OTT는 지금 → 미디어 인사이트** 다섯 탭으로 구성합니다. 미디어 인사이트는 기본으로 최근 30일 발표를 표시하며 기간을 직접 바꿀 수 있습니다.

미디어 인사이트의 **리서치 질문하기**에서 가격·브랜딩·제휴 등 사업 질문을 바로 입력할 수 있습니다. 전체 저장 자료와 질문에 맞춰 확보한 공식 원문을 참고해 사실·해석·검토안·가정과 추가로 확인할 정보를 나눠 답합니다. 최신 원문을 확보하지 못하면 저장 자료를 참고했다는 상태를 표시합니다. 확인한 날짜와 발표 날짜는 구분하며, 과거 가격을 현행 요금으로 확정하지 않습니다.

대화·사업 조건·직접 채택한 결정은 프로젝트별로 보관합니다. **사업 조건·프로젝트 관리**에서 사업 조건과 결정을 수정하고 복구 코드로 이전 프로젝트를 다시 열 수 있습니다. 복구 코드는 기록을 여는 열쇠이므로 별도로 보관해야 합니다. 프로젝트 목록이나 다른 사용자의 대화는 공개하지 않습니다. 기존 저장소 연결이 있으면 로컬과 GitHub에 AES-256-GCM 암호문으로 보관하며, 연결이 없거나 실패하면 현재 앱 저장 상태를 표시합니다. 앱 재설치·재부팅 후 복구에는 원격 백업 완료와 복구 코드가 모두 필요합니다.

질문을 제출할 때 공개 자료 검색 1회와 AI 분석을 실행합니다. 일반 열람·탭 이동·결정 채택·저장 재시도는 모델을 호출하지 않습니다. 하단 AI 사용량에는 반환된 검색·분석 응답을 기록하며, 웹 검색 도구 비용을 포함한 실제 결제는 제공사 내역에서 확인합니다. 자료 출처가 붙은 사실도 확보한 발췌 범위의 검증이며, 해석·전략 제안의 성공을 보장하지 않습니다.

프로젝트 백업은 기본 GitHub 연결을 사용합니다. 선택적으로 `RESEARCH_GITHUB_REPO`, `RESEARCH_GITHUB_TOKEN`, `RESEARCH_GITHUB_BRANCH`, `RESEARCH_GITHUB_PATH`로 별도 저장소를 지정할 수 있습니다. 기본 경로는 `research_projects/`이고 평문 질문·답변·복구 코드를 저장소에 기록하지 않습니다.

‘지금 주목할 이야기’는 상위 10개 작품을 가로로 넘겨 봅니다. PC에서는 카드를 잡아 드래그하거나 화살표·키보드로, 모바일에서는 가로 스크롤로 이동합니다. ‘새로운 소식’은 뉴스에서 선정한 개봉·공개·캐스팅·제작 소식을 소개합니다. 각 작품에는 실제 선정 근거와 관련 기사 원문을 연결합니다. 출처별 집계와 선정 기준은 [ISSUE_QUALITY.md](ISSUE_QUALITY.md)에 있습니다.

‘추천 테마’는 기존처럼 최근 수집 이슈에서 테마를 생성합니다. ‘테마 생성하기’를 누르면 추천 작품과 포스터까지 연결하고, ‘콘텐츠 새로고침’으로 작품만 갱신합니다. ‘테마 라이브러리’에는 빠른 검색·상태 필터·다운로드와 작품 관리가 남습니다. 카드에는 연결된 이슈·테마명·기획 의도·추천 작품 포스터를 표시하며 모바일에서는 가로로 넘길 수 있습니다.

새 테마는 작품의 공통 주제·닮은 장르·감상 상황을 짧고 자연스럽게 암시합니다. 조회수·클립 반응 보고형 제목은 제외하고 ‘가족이라는 미스터리’처럼 함축적인 주제도 허용합니다. 작품 포함·제외 기준과 참고 후보를 함께 기획하고, 콘텐츠 연결·새로고침에도 같은 기준을 전달합니다. 기존 저장 테마를 일괄 개명하지 않습니다. 상세 기준은 [테마 생성](THEME_GENERATION.md)에 있습니다.

‘AI 디렉터’는 원하는 주제·장르·분위기를 바로 입력하는 독립 기획 공간입니다. 시작 버튼이나 사전 선택 없이 기본 테마 1개와 실제 추천 작품 5~10편을 만들고, 이후 대화로 제목·카피·작품·분위기를 고쳐갑니다. 여러 테마가 필요하면 원하는 개수를 요청합니다. 라이브러리의 문장형 AI 검색도 이 대화로 옮겼으며 실제 저장 테마를 찾아 새 기획으로 이어갑니다. 실제 콘텐츠 DB로 작품과 포스터를 연결합니다. **디렉터 초안은 대화에만 보관하며 ‘최종 채택’한 테마만 DB·추천 이력·작품 후보에 추가**합니다. 작품 존재 확인을 B tv 서비스 가능 여부로 단정하지 않습니다. [AI_DIRECTOR.md](AI_DIRECTOR.md)에 상세 동작이 있습니다.

‘OTT는 지금’은 넷플릭스·티빙·쿠팡플레이·디즈니+·웨이브의 주요 공개 소식을 매거진으로 소개합니다. 개별 서비스에서는 원래 목록명·작품·이미지·배치·확인 시각을 봅니다. 쿠팡플레이 홈 접근이 제한되면 공식 채널 소식을 별도로 표시합니다. 개인 추천이나 계정 연결은 수집하지 않습니다. 공개 홍보 화면과 실제 콘텐츠 홈을 구분하고, 실패한 수집은 목록 0개로 계산하지 않습니다. 매일 오전 10시 KST 수집하며 해외 서버의 결과를 한국 지역 홈과 동일하다고 단정하지 않습니다. [OTT_CURATION.md](OTT_CURATION.md)를 참고하세요.

‘미디어 인사이트’는 공식 자료에서 **주요 이슈 최대 6건**을 추려 관련 이미지와 한글 제목·요약으로 보여줍니다. 기존 **전체·스포츠·콘텐츠·제휴·유통 등의 주제 필터 행에 ‘국내 이슈’를 추가**합니다. 국내 콘텐츠 공개·제작·편성·미디어 산업 변화부터 IPTV·OTT의 요금·결합·상품·이용 조건까지 공식 원문에서 확인한 소식을 살펴봅니다. 별도 범위 탭을 만들지 않으며 기존 다섯 개 최상위 탭을 유지합니다. 모든 수집 문서는 별도 보관함에 남고, 최신 자료라는 이유만으로 주요 이슈에 채우지 않습니다. 원문 문장·PDF 페이지, 사실·해석·B tv 검토 선택지를 구분한 분석, 관련 자료 비교·리서치 질문·내보내기를 유지합니다. 매일 오전 9시 KST 자료를 수집하고 새 영문 자료의 한글 정리를 한 번 저장합니다. 일반 열람·필터에서는 AI를 호출하지 않으며 접근 실패 시 이전 자료와 날짜를 유지합니다. 연결 범위와 선정·비용 기준은 [MEDIA_INSIGHTS.md](MEDIA_INSIGHTS.md)에 있습니다.

포스터는 작품명·연도·종류가 맞는 자료를 사용합니다. 없거나 이미지가 열리지 않으면 작품명 카드가 남습니다. 일반 페이지 새로고침에서는 생성이나 포스터 검색을 반복하지 않습니다. `Repair saved theme posters` 작업은 작품과 순서를 유지하며 기존 추천의 빈 포스터만 보완합니다. 결과는 `artifacts/poster_repair_status.json`에 기록합니다.

앱 버전은 `VERSION`, 변경 내역은 [CHANGELOG.md](CHANGELOG.md), 실제 배포 확인은 `artifacts/deployment_validation.json`에서 봅니다. 고정 태그를 덮어쓰지 않으며 [롤백 도구와 절차](ROLLBACK.md)는 최신 테마·추천·수집 데이터를 유지하면서 코드만 되돌립니다. 이전 LLM 설정 참고 자료는 [PHASE2A_LLM_NOTES.md](PHASE2A_LLM_NOTES.md)에 있습니다.

하단의 작은 ‘AI 비용·잔액’에서 과금 작업, 이번 접속의 반환 응답 수·토큰, OpenAI 잔액 확인 링크를 봅니다. 선택적으로 프로젝트 월 사용액과 설정 예산의 남은 금액을 연결할 수 있습니다. 충전 잔액을 추정 숫자로 표시하지 않으며 설정은 [비용 안내](API_COSTS.md)를 참고하세요.

조회·검색 속도 개선의 처리 방식과 전후 측정 결과는 [PERFORMANCE.md](PERFORMANCE.md)를 참고하세요. 라이브러리는 전체 테마에서 검색한 결과를 24개씩 보여줍니다.
