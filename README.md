# B tv+ AI Theme Curator — LLM Theme Generation

이번 버전은 기존 500개 테마를 재정렬하지 않고, 최근 핵심 이슈에서 LLM이 신규 테마를 생성합니다.

- 신규 생성 시 기존 DB 미참조
- 생성 후 기존 DB와 사후 중복·품질 검수
- `[AI 신규 생성]` / `[기존 DB 활용]` 구분
- 채택된 신규 테마 자동 DB 합류
- 추천 이력 저장으로 최근 반복 방지
- 향후 추천 테마 전체 콘텐츠 후보 일괄 연결 구조 준비

자세한 설정은 `PHASE2A_LLM_NOTES.md`를 확인하세요.

각 이슈에서 YouTube 인기 영상 포함 여부·조회수·관객 수·순위·작품의 새 소식 등 선정 이유를 확인할 수 있습니다. 홈의 ‘새로운 소식’에서 뉴스로 선정된 작품을 소개하고, ‘선정 근거’의 원문 링크 아래에는 같은 작품의 관련 기사를 함께 보여줍니다. 출처별 후보 조건과 화면 배치 순서, 검증 방법은 [ISSUE_QUALITY.md](ISSUE_QUALITY.md)에 정리했습니다.

‘지금 주목할 이야기’는 상위 10개 작품을 가로로 넘겨 봅니다. PC에서는 카드를 잡아 드래그하거나 화살표·키보드로, 모바일에서는 가로 스크롤로 이동하며 ‘새로운 소식’은 별도로 표시합니다.

홈의 ‘이번 주 추천 테마’에서 테마 생성하기를 누르면 테마를 저장한 뒤 추천 작품과 포스터까지 함께 채웁니다. 옆의 ‘콘텐츠 새로고침’과 ‘테마 라이브러리’에서 추천 작품을 갱신하거나 전체 테마로 이동합니다. 생성 개수·연결 설정과 생성 기록은 접어두고, 카드에는 연결된 이슈·테마명·추천 이유·작품 포스터 5개를 보여줍니다. 모바일 포스터는 가로로 넘길 수 있으며 전체 후보는 펼쳐서 확인합니다.

작품 정보와 실제 포스터 주소를 함께 저장합니다. 포스터는 작품명·연도·종류가 맞는 자료를 사용하며, 찾지 못하거나 이미지가 열리지 않으면 작품명 카드가 남습니다. 콘텐츠를 채우는 데 실패해도 생성한 테마는 보존하며, 옆의 콘텐츠 버튼으로 해당 테마의 작품만 다시 불러올 수 있습니다. 일반적인 페이지 새로고침에서는 생성이나 포스터 검색을 반복하지 않습니다.

포스터 조회 코드를 변경하면 `Repair saved theme posters` 작업이 기존 추천의 빈 이미지 주소를 보완합니다. 제목·연도·작품 종류가 일치할 때 포스터만 추가하고 추천 작품과 순서는 유지합니다. 결과는 `artifacts/poster_repair_status.json`에 기록하며, 테마나 콘텐츠를 다시 생성하지 않습니다.

홈은 **지금 주목할 이야기 → 추천 테마 → OTT는 지금** 세 탭으로 나뉩니다. ‘OTT는 지금’은 넷플릭스·티빙·쿠팡플레이·디즈니+·웨이브의 공개 홈을 비교합니다. 메인 배너와 원래 목록명·구성 작품·이미지·홈 순서·확인 시각을 저장하고, 테마·신작·순위 목록을 구분합니다. 개인 추천이나 계정 연결은 수집하지 않습니다.

수집된 자료만 표시하며 공개 홍보 화면과 실제 콘텐츠 홈을 구분합니다. 실패한 수집은 목록 0개로 계산하지 않고 이전 정상 자료와 날짜를 보존합니다. 해외 수집 서버의 결과를 한국 지역 홈과 동일하다고 단정하지 않습니다. 수집·검증·운영 방법은 [OTT_CURATION.md](OTT_CURATION.md)를 참고하세요.
