# B tv+ AI Theme Curator

현재 버전은 `v1.6.3`입니다. **지금 주목할 이야기 → 추천 테마 → AI 디렉터 → OTT는 지금 → 미디어 인사이트** 다섯 탭으로 구성합니다. 미디어 인사이트는 기본으로 최근 30일 발표를 표시하며 기간을 직접 바꿀 수 있습니다. 선택한 분류에 자료가 3건 미만이면 해당 분류의 기간만 90일·365일·전체로 순차 확대하고 실제 발표일을 유지합니다.

미디어 인사이트는 **공개 자료 전용 모니터링**입니다. 자유 질문, 사업 조건 입력, 프로젝트 대화·결정 저장은 운영 화면과 실행 경로에서 제거했습니다. **공개 자료 비교**에서 사업자와 문서를 선택해 공식 발표 흐름과 실제 저장된 동일 원문의 전후 내용을 확인합니다. 이전 기록이 없으면 이를 표시하며, 다른 상품·국가의 가격을 임의로 비교하지 않습니다.

과거 암호화 기록은 임의로 삭제하지 않으며 새 화면에서 읽거나 전송하지 않습니다. 이전 대화의 브라우저 세션 상태도 새 실행에서 해제합니다. 테마·추천 이력·OTT와 공개 미디어 자료는 유지합니다.

공개 자료 비교·열람·필터는 모델을 호출하지 않습니다. 선택한 공개 원문의 ‘분석 노트 만들기’와 영문 자료의 ‘한글 정리’는 명시적 작업이며 기존 AI 연결을 사용합니다. 공개 원문만 전달하고 내부 원가·실적·미공개 전략을 입력하는 필드는 제공하지 않습니다.

개발 환경은 `pip install -r requirements-dev.txt`로 설치합니다. 과거 암호화 형식의 회귀 검증에만 필요한 패키지는 운영 의존성과 분리합니다.

‘지금 주목할 이야기’는 상위 10개 작품을 가로로 넘겨 봅니다. PC에서는 카드를 잡아 드래그하거나 화살표·키보드로, 모바일에서는 가로 스크롤로 이동합니다. ‘새로운 소식’은 실제 기사 발행 시각순으로 최근 7일 소식을 최대 4개 보여줍니다. 같은 작품·사건의 반복 보도는 줄이고 다른 작품을 우선합니다. 전체 수집은 오전 8시 KST에 유지하고, 뉴스는 02·14·20시에 추가 수집합니다. 열린 소식 영역은 5분마다 저장 자료를 다시 읽으며 모델·추가 YouTube API를 호출하지 않습니다. 출처별 집계와 선정 기준은 [ISSUE_QUALITY.md](ISSUE_QUALITY.md)에 있습니다.

‘추천 테마’는 기존처럼 최근 수집 이슈에서 테마를 생성합니다. ‘테마 생성하기’를 누르면 추천 작품과 포스터까지 연결하고, ‘콘텐츠 새로고침’으로 작품만 갱신합니다. ‘테마 라이브러리’에는 빠른 검색·상태 필터·다운로드와 작품 관리가 남습니다. 테마마다 추천 작품 10편을 연결합니다. 카드에는 연결된 이슈·테마명·기획 의도와 전체 추천 작품 포스터를 표시하며, PC에서는 포스터를 잡아 드래그하고 모바일에서는 스와이프해 넘깁니다. 화살표·키보드 이동도 지원합니다. 포스터 연결과 실제 이미지 확인은 명시적 생성·새로고침·보완 작업에서만 수행합니다. 탭을 바꿀 때는 화면 높이와 스크롤바 공간을 유지합니다.

새 테마는 작품의 공통 주제·닮은 장르·감상 상황을 짧고 자연스럽게 암시합니다. 조회수·클립 반응 보고형 제목은 제외하고 ‘가족이라는 미스터리’처럼 함축적인 주제도 허용합니다. 작품 포함·제외 기준과 참고 후보를 함께 기획하고, 콘텐츠 연결·새로고침에도 같은 기준을 전달합니다. 기존 저장 테마를 일괄 개명하지 않습니다. 상세 기준은 [테마 생성](THEME_GENERATION.md)에 있습니다.

‘AI 디렉터’는 원하는 주제·장르·분위기를 바로 입력하는 독립 기획 공간입니다. 시작 버튼이나 사전 선택 없이 기본 테마 1개와 실제 추천 작품 5~10편을 만들고, 이후 대화로 제목·카피·작품·분위기를 고쳐갑니다. 여러 테마가 필요하면 원하는 개수를 요청합니다. 라이브러리의 문장형 AI 검색도 이 대화로 옮겼으며 실제 저장 테마를 찾아 새 기획으로 이어갑니다. 실제 콘텐츠 DB로 작품과 포스터를 연결합니다. **디렉터 초안은 대화에만 보관하며 ‘최종 채택’한 테마만 DB·추천 이력·작품 후보에 추가**합니다. 작품 존재 확인을 B tv 서비스 가능 여부로 단정하지 않습니다. [AI_DIRECTOR.md](AI_DIRECTOR.md)에 상세 동작이 있습니다.

‘OTT는 지금’은 넷플릭스·티빙·쿠팡플레이·디즈니+·웨이브의 주요 공개 소식을 매거진으로 소개합니다. 개별 서비스에서는 원래 목록명·작품·이미지·배치·확인 시각을 봅니다. 쿠팡플레이 홈 접근이 제한되면 공식 채널 소식을 별도로 표시합니다. 개인 추천이나 계정 연결은 수집하지 않습니다. 공개 홍보 화면과 실제 콘텐츠 홈을 구분하고, 실패한 수집은 목록 0개로 계산하지 않습니다. 매일 오전 10시 KST 수집하며 해외 서버의 결과를 한국 지역 홈과 동일하다고 단정하지 않습니다. [OTT_CURATION.md](OTT_CURATION.md)를 참고하세요.

‘미디어 인사이트’는 공식 자료에서 **주요 이슈 최대 6건**을 추려 관련 이미지와 한글 제목·요약으로 보여줍니다. 기존 **전체·스포츠·콘텐츠·제휴·유통 등의 주제 필터 행에 ‘국내 이슈’를 추가**합니다. 국내 콘텐츠 공개·제작·편성·미디어 산업 변화부터 IPTV·OTT의 요금·결합·상품·이용 조건까지 공식 원문에서 확인한 소식을 살펴봅니다. 별도 범위 탭을 만들지 않으며 기존 다섯 개 최상위 탭을 유지합니다. 모든 수집 문서는 별도 보관함에 남고, 최신 자료라는 이유만으로 주요 이슈에 채우지 않습니다. 원문 문장·PDF 페이지, 사실·해석·B tv 검토 선택지를 구분한 분석, 공개 자료 비교와 내보내기를 제공합니다. 매일 오전 9시 KST 자료를 수집하고 새 영문 자료의 한글 정리를 한 번 저장합니다. 일반 열람·필터에서는 AI를 호출하지 않으며 접근 실패 시 이전 자료와 날짜를 유지합니다. 연결 범위와 선정·비용 기준은 [MEDIA_INSIGHTS.md](MEDIA_INSIGHTS.md)에 있습니다.

OTT의 ‘소식 새로고침’ 아래에서 작품 제목으로 시청 서비스를 검색합니다. 키노라이츠 공개 정보에서 구독·대여·구매와 확인 시각·원문 링크를 표시하고, 동명 작품은 제작 연도로 구분합니다. 검색 버튼을 누를 때만 조회하며 일반 화면 전환과 모델 호출은 연결하지 않습니다. 미디어 기사 제목을 누르면 옆 분석 노트만 갱신하며 보던 위치를 유지합니다. 팝업은 ‘분석 노트 크게 읽기’를 눌렀을 때만 열립니다.

포스터는 작품명·연도·종류가 맞는 자료를 사용합니다. 없거나 이미지가 열리지 않으면 작품명 카드가 남습니다. 일반 페이지 새로고침에서는 생성이나 포스터 검색을 반복하지 않습니다. `Repair saved theme posters` 작업은 작품과 순서를 유지하며 기존 추천의 빈 포스터만 보완합니다. 결과는 `artifacts/poster_repair_status.json`에 기록합니다.

앱 버전은 `VERSION`, 변경 내역은 [CHANGELOG.md](CHANGELOG.md), 실제 배포 확인은 `artifacts/deployment_validation.json`에서 봅니다. 고정 태그를 덮어쓰지 않으며 [롤백 도구와 절차](ROLLBACK.md)는 최신 테마·추천·수집 데이터를 유지하면서 코드만 되돌립니다. 이전 LLM 설정 참고 자료는 [PHASE2A_LLM_NOTES.md](PHASE2A_LLM_NOTES.md)에 있습니다.

하단의 작은 ‘AI 비용·잔액’에서 과금 작업, 이번 접속의 반환 응답 수·토큰, OpenAI 잔액 확인 링크를 봅니다. 선택적으로 프로젝트 월 사용액과 설정 예산의 남은 금액을 연결할 수 있습니다. 충전 잔액을 추정 숫자로 표시하지 않으며 설정은 [비용 안내](API_COSTS.md)를 참고하세요.

조회·검색 속도 개선의 처리 방식과 전후 측정 결과는 [PERFORMANCE.md](PERFORMANCE.md)를 참고하세요. 라이브러리는 전체 테마에서 검색한 결과를 24개씩 보여줍니다.
